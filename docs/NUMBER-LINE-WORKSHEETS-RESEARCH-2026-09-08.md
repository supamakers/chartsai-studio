## One URL and an actual resource

`/number-line-worksheets/` owns multi-question printable practice. The existing `/number-line-generator/` remains the custom single-diagram tool for points, intervals, decimal steps and blank lines. Link the two explicitly. Three original packs live as sections of one page, with A4/Letter PDFs, CSV and editable preset handoffs. Do not create indexed variants for each denominator, question count, paper size or set number.

The resource generates 6, 9 or 12 exercises; three per page with working space. It uses the existing number-line renderer, reproducible sets and distinct exercise specifications, preserving question order in separate answer pages. Fraction windows span two units within 0–5. Addition/subtraction uses positive operands and unit jumps. It makes no curriculum alignment or automatic grading claim.

## Discovery, answer clarity and validation

Static HTML includes instructions, examples, scale rules, simplified-fraction behavior, common mistakes, limitations, byline, internal links and direct downloads. SoftwareApplication and breadcrumb schema describe visible features. The canonical omits query states; sitemap, allowlisted analytics paths and public health checks include the new route. Analytics receives fixed tool/action/format identifiers, never questions or seeds.

Release checks cover deterministic generation, unique exercise specifications, arithmetic and bounds across thousands of settings, question/key separation, all PDF pages and paper sizes, visible rendering, mobile use, preset handoffs and actual downloaded artifacts. These are functional checks, not evidence of indexing, rankings, adoption or AI citations.
