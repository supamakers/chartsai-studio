## Analytics configuration and limits

Existing Plausible property: https://plausible.io/chartsai.com. Five custom goals were saved: Chart Download, Data Import, Example Loaded, Source Download, SupaMakers Visit. Both `tool` and `format` custom properties were saved; historical goals remain. No plan upgrade or second analytics provider was added.

The production script loaded successfully. An explicit installation test sent a pageview and Chart Download with only canonical URL and fixed tool/format properties; the endpoint returned HTTP 202. A follow-up inspection found `x-plausible-dropped: 1`: the traffic was filtered, and the dashboard still showed zero visitors for launch day. Plausible documents this as bot filtering. Therefore **normal-visitor ingestion into the dashboard remains unverified**. Do not treat HTTP 202 alone as proof of recorded analytics. No bot filter was disabled and no visitor IP was fabricated. Normal QA uses `?analytics=off`; the few explicit installation visits around 07:26–07:30 UTC are test activity, not adoption.

The existing IP and hostname settings showed no configured exclusion rules. Automated-client filtering can occur independently of those settings. See [Plausible's events API debugging reference](https://plausible.io/docs/events-api#debugging) and [our measurement definitions](MEASUREMENT.md).

## Validation

- 46 unit tests and 13 browser tests passed before cutover. Astro check reported zero errors, warnings or hints; the static build checked twelve pages and their metadata, schema, assets and sitemap inclusion.
- Actual SVG downloads from all three chart makers and an actual habit-tracker PDF were verified on the live domain. Mobile widths, data import validation, PNG dimensions, SVG escaping, ECharts configuration exports, leap days and PDF paper sizes were covered by browser tests.
- A live printable export revealed a roughly 24 MB uncompressed raster PDF. Lossless compression reduced the tested A4/Letter examples to about 202/205 KB while retaining print dimensions; the PDF export test now prevents files over 2 MB for these fixtures.
- The dynamically loaded chart engine still produces a bundle-size warning. No production Core Web Vitals improvement or SEO result is claimed.
