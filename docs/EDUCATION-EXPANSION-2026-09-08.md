Checked September 8, 2026. The user authorized implementing the remaining educational tools after the coordinate-plane pilot. This release adds four focused tool pages and `/math-tools/`, a curated navigation hub. Together with the pilot, the collection has five working tools. Settings, equations, paper sizes and example selections do not generate indexable URLs.

Primary product pages inspected for actual competing formats:

- [Figwise number-line generator](https://figwise.app/number-line-generator): fractions, points, intervals and SVG/PNG already exist.
- [Math Learning Center number line](https://www.mathlearningcenter.org/apps/number-line): an established open-ended educational tool.
- [Calculator.net slope calculator](https://www.calculator.net/slope-calculator.html): two-point calculation, formula and special cases.
- [SubjectCoach transformations worksheets](https://www.subjectcoach.com/generator/transformations): printable transformation practice already exists.
- [GeoGebra quadratic graph](https://www.geogebra.org/m/scUHdsQ2): coefficient controls and quadratic properties already exist.
- [GeoGebra transformation manual](https://geogebra.github.io/docs/manual/en/tools/Transformation_Tools/): mature general-purpose transformation tools.

The user benefit is a consistent explanation/practice/download journey with accurate answer separation and original ready-to-use sheets. It is not a claim that these operations are novel or that this product is a replacement for Desmos or GeoGebra.

## Page-specific value and validation

- Number line: exact uniform spacing, fractional/negative input, signed repeated jumps, finite open/closed intervals, repeated values retained, question/key separation.
- Slope: signed differences in consistent order, two distinct source points, zero/undefined slope, equation, native ECharts line and rise/run construction, equal units.
- Geometry: original/image correspondence, translation and four reflection lines, quarter-turn rotations around a chosen centre, positive dilation, simple-polygon checks, automatic range containing every vertex, equal physical units.
- Quadratic: bounded standard-form coefficients, vertex/discriminant/real roots, stable numerical quadratic formula, zero/repeated/no-real-root cases, sampled native ECharts curve, disclosed independent axis scales.

All pages have a static answer, input requirements, original worked calculation, downloadable two-page worksheets in A4 and Letter, visible methodology and limits, relevant reference, authorship, internal links and matching SoftwareApplication/Breadcrumb markup. The hub has a truthful ItemList. No review/rating schema or invented pedagogical credentials. AEO/GEO readiness is source clarity and accessible content, not a guaranteed citation.

The public source archive remains allowlisted. Generated math assets are rebuilt, excluded from Git and the source ZIP. Bounded analytics use four fixed tool identifiers and approved public filenames; entered values never become analytics properties or indexed URLs.

## Skill evidence

The chart-quality skill is applied internally. Its deterministic checker and application tests verify specific data and geometry properties. The evaluation task set freezes original prompts and sources for seven scenarios, but no fresh-context model comparison has been run in this release. No improvement percentage, model benchmark result or public skill landing page is justified by these tests. Keep the skill labelled experimental until an actual matched comparison is recorded.
