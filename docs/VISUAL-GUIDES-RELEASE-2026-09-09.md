# Visual guides and discovery — v0.13.0

September 9, 2026. Implements the production audit's next release on the existing 119 canonical routes. Publication verification is recorded after deployment.

## What changed

- Six existing guides now show twelve original native ECharts figures with paired same-data explanations, accessible raw tables, explicit methods and 36 SVG/PNG/CSV assets. Eight supported views open exact observations/settings in existing makers. Log/pie/truncated-bar teaching figures make their limits clear; normal bar makers retain zero.
- Iris adds a species-aware grouped box plot, retaining all 150 original source rows, 50 per species, with full CSV/editor handoff. Numerical display precision is separated from preserved raw values.
- About, Source, Privacy and agent current-scope instructions match the expanded product. Source version comes from package metadata. Fictional MIT examples, CC0 templates and attributed source data have separate reuse descriptions.
- Examples exposes editorial collections, Charts covers all eleven chart decisions, relevant time-series guides link the NASA resource, and old legal aliases map to current equivalent pages. Retired account/blog URLs are not blanket-redirected.
- Shared decorative paper/ink textures are compressed without changing layout or identity; the main heading and page-appropriate body Latin fonts are preloaded.
- Guide selections/downloads use existing Plausible goals with fixed guide identifiers; template attribution remains unchanged.
